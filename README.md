# Norhan Awad · Portfolio

Personal portfolio of Norhan Awad, Full Stack Django Developer.

**Live:** https://norhanawad848.github.io/my-portofolio/

A static site with plain HTML, CSS and JavaScript and no build step. It has light and dark themes and a responsive layout.

- `index.html`: page content
- `styles.css`: styles and theme tokens
- `main.js`: theme toggle, mobile menu, scroll animations
- `assets/`: photo and CV
- `portfilio.html`: redirect from the old URL
